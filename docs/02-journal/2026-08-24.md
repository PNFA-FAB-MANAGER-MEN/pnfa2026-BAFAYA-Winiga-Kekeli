- Les rituels quotidiens imposés : réunion debout chaque matin (10 min), synchronisation du dépôt à midi et le soir, entrée de journal dans les 15 dernières minutes, revue de jalon et release chaque samedi
- Les 3 espaces de travail : poste local (VSCode) → historique local (Git) → dépôt distant (GitHub) → site publié (GitHub Pages), avec 3 conséquences : un commit seul ne publie rien, la synchronisation descend avant de monter, le site a 1 à 2 minutes de retard
- La syntaxe Markdown de base : titres (`#`), gras (`**`), italique (`*`), listes à puces et cases à cocher, liens, images, code, citations, tableaux
- Les 3 pièges Markdown : l'espace après `#` et après le tiret, une ligne vide avant une liste ou un tableau, une ligne vide pour changer de paragraphe
- Règle rappelée par le formateur : un travail non poussé sur GitHub et non journalisé le jour même est réputé ne pas avoir eu lieu
